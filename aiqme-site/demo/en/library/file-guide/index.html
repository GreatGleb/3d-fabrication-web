How to prepare a file for 3D printing

From measurement units to critical surfaces: what to check before submitting a model.

EN · AIQME informational guide

Start with the intended use

Explain where the part will be used, whether it carries a load and whether it mates with other parts. This supports material and process selection.

Check the scale

Record the measurement units when exporting STL or OBJ. Compare at least one known dimension in the viewer. Do not scale a part simply to fit the build area.

Identify critical features

Add a drawing or photo identifying critical dimensions, holes and surfaces. An automatic price does not replace engineering suitability review.

Specific manufacturing limits are set for each project.
