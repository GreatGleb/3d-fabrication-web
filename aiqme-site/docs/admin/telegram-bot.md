# Telegram-бот AIQME: инструкция администратора

Бот позволяет менять тексты, картинки и видео сайта прямо из Telegram: создать черновик, поправить поле,
посмотреть результат и опубликовать на литовской (LT) или английской (EN) версии сайта. Заказов, клиентов и
платежей в боте нет — они только в веб-админке.

**Как пользоваться этой инструкцией.** Прочитайте один раз раздел [«Основы»](#основы), а дальше открывайте
главу нужного вида контента:

| Вид контента | Кнопка в боте (EN / LT) | Где на сайте | Глава |
|---|---|---|---|
| Тексты страниц | Page texts / Puslapių tekstai | главная, «О нас», контакты, обучение, правовые страницы | [→](#тексты-страниц) |
| Услуги | Services / Paslaugos | `/lt/paslaugos/…` | [→](#услуги) |
| Проекты | Projects / Projektai | `/lt/projektai/…` | [→](#проекты) |
| Статьи | Articles / Straipsniai | `/lt/naujienos`, `/lt/biblioteka/…` | [→](#статьи) |

| Товары | Products / Produktai | `/lt/produktai/…` | [→](#товары) |

## Основы

### Подключение (один раз)

Бот слушается только одного человека — администратора сайта, к чьему Telegram он привязан. Чужие сообщения
он молча игнорирует.

1. Войдите в веб-админку сайта и откройте **Integrations**.
2. В разделе Telegram нажмите кнопку получения кода. Код показывается **один раз** и действует **10 минут**.
3. В Telegram откройте **бот компании** (не @BotFather!) и отправьте ему `/start <код>`.
4. Бот ответит **Chat linked** (*Pokalbis susietas*) и покажет меню. В админке появится «Connected».

Чтобы передать бот другому человеку, он получает новый код и отправляет `/start <код>` со своего аккаунта —
привязка переходит к нему. Код никому не пересылайте: после использования он сгорает, но до этого им можно
привязать чужой аккаунт. После 5 неверных кодов подряд бот на 10 минут перестаёт принимать коды.

### Язык бота

Бот говорит на языке вашего Telegram: литовский интерфейс Telegram — ответы и кнопки по-литовски, любой
другой — по-английски. В этой инструкции надписи даны по-английски, литовские — в скобках там, где это важно.

### Как устроено меню

```
Choose a content type            ← главное меню: виды контента
  └ Projects                     ← список записей этого вида + «Add a draft +» и «← Back»
      └ Testas W-22 · Projects   ← карточка записи
          LT / EN                ← кнопки языковых версий
          Related services …     ← общие для обоих языков настройки (атрибуты)
          + Image                ← добавить картинку / видео
          └ Testas W-22 · LT     ← карточка языковой версии: пронумерованные поля
              1 2 3 4 …          ← номер = кнопка правки поля
              Preview draft
              Publish LT / Unpublish LT
```

- **Открыть меню**: отправьте боту любое сообщение, когда он ничего у вас не спрашивал (например, «меню»).
  Если бот как раз ждёт текст поля, это сообщение станет текстом поля — сначала закончите или нажмите «← Back».
- **← Back** (*Atgal*) — на уровень выше.
- Бот ждёт ваш ответ на вопрос **30 минут**; потом вопрос забывается — начните снова с кнопки.

### Черновик и публикация

У каждой записи две независимые языковые версии — LT и EN. Каждая живёт так:

| Состояние (EN / LT) | Что значит | Что видно на сайте |
|---|---|---|
| Not created / *Nesukurta* | версии на этом языке нет | страница этого языка — 404 |
| Draft / *Juodraštis* | версия есть, ни разу не опубликована | 404 |
| Published / *Paskelbta* | опубликована последняя правка | текущий текст |
| Unpublished changes / *Yra nepaskelbtų pakeitimų* | опубликована, но после этого были правки | **старый** опубликованный текст, пока не нажмёте Publish |

- **Каждая правка поля сохраняется сразу как черновик** (ответ *Draft saved.* / *Juodraštis išsaugotas.*),
  но на сайт **не попадает**, пока вы не нажмёте **Publish LT** (или **Publish EN**) в карточке этой версии.
  Можно спокойно поправить несколько полей и опубликовать один раз.
- **Preview draft** — показывает весь текст последней правки в чате, перед публикацией.
- **Publish LT/EN** публикует только этот язык; другой язык не меняется.
- **Unpublish LT/EN** снимает этот язык с сайта (страница снова 404). Текст не удаляется, его можно опубликовать снова.

### Правка поля

1. Карточка записи → кнопка языка (**LT** или **EN**).
2. Нажмите **номер поля** под списком.
3. Бот пришлёт название поля и **текущий текст** — его удобно скопировать, поправить и отправить обратно.
4. Отправьте новый текст **одним сообщением**. Бот ответит *Draft saved.* и покажет карточку снова.

Особые виды полей:

- **Список** (например, «Block points», «Problems» у услуг): каждая строка сообщения — отдельный пункт.
  Новая строка в Telegram — Shift+Enter (на телефоне — обычный перенос строки). Пустые строки отбрасываются.
- **Пары и разделы** («Section 1 · Heading», «Section 1 · Text», «process_steps 2 · Title»): у каждого блока
  отдельные поля для заголовка и текста, правьте их по одному.
- Длина: строка — до 255 символов, текст — до лимита сайта; если превысить, бот ответит ошибкой, правка не сохранится.
- **Очистить поле через бот нельзя**: Telegram не отправляет пустые сообщения, а «—» сохранится как текст.
  Очищайте поля в веб-админке.

### Атрибуты записи

Кнопки в карточке записи между языками и медиа (например, *Related services*, *Category*, *Date*). Они общие
для LT и EN и **применяются на сайте сразу**, без публикации (ответ *Saved.* / *Išsaugota.*).

- **Выбор одного варианта**: нажмите вариант; выбранный отмечен «✓». Повторное нажатие снимает выбор.
- **Несколько вариантов**: каждое нажатие отмечает или снимает вариант.
- **Дата**: отправьте текстом в виде `ГГГГ-ММ-ДД`, например `2026-11-15`.
- **Ссылка**: полный адрес, начинающийся с `https://`.

### Картинки и видео

1. Карточка записи → кнопка **+ <назначение>** (например, **+ Image**).
2. Бот попросит файл. Отправьте **одно** фото или видео.
3. Ответ *File uploaded.* (*Failas įkeltas.*) — в карточке растёт счётчик (например, «Image: 1»).

- Форматы: картинки — JPEG, PNG, WebP; видео — MP4; размер — **до 20 МБ**. Формат проверяется по содержимому
  файла, переименование не поможет. HEIC с iPhone не принимается — пересохраните в JPEG.
- **Качество**: Telegram сжимает фото, отправленное «как фото». Для фото на сайт отправляйте **файлом**
  (скрепка → «Файл» / «Отправить без сжатия»).
- Есть назначения на **один файл** (новый файл **заменяет** прежний) и на **несколько** (новый добавляется
  к галерее) — указано в главе каждого вида.
- Картинки появляются на сайте **сразу**, без публикации. Если версия на языке ещё не опубликована, страницы
  всё равно не видно.
- Удалить картинку или поменять порядок через бот нельзя — только в веб-админке.
- Файл без нажатой кнопки «+ …» бот не примет: ответит *Choose a record and the file purpose first.*

### Новая запись

1. Меню → вид контента → **Add a draft +** (*Pridėti juodraštį +*).
2. Бот попросит **заголовок (LT)** — отправьте.
3. У видов с собственной страницей бот попросит **URL (LT)**: латинские строчные буквы, цифры и дефисы,
   например `restauruota-detale`. Это хвост адреса страницы, его потом лучше не менять.
4. Бот покажет карточку LT-версии со статусом **Draft**. Заполните поля, при необходимости добавьте картинки
   и нажмите **Publish LT**.

Новые записи создаются только на литовском. Удалить запись через бот нельзя.

### Английская версия (EN)

Карточка записи → **EN** → поля, как у LT; публикация — **Publish EN**.

> **Известное ограничение (на 24.10.2026).** У видов с собственным адресом — **услуги, проекты, статьи, товары,
> категории** — первую EN-версию через бот создать нельзя: бот сохраняет поля по одному, а для новой версии
> заголовок и URL нужны сразу; он отвечает «Invalid value: slug» или «Invalid value: title». **Как обойти**:
> создайте EN-версию в веб-админке (заполните заголовок и URL вместе и сохраните), дальше правьте и публикуйте
> её в боте. У обучения, FAQ, производителей и текстов страниц ограничения нет — начните с поля **Title**.

### SEO-поля

У страниц, услуг, проектов, статей и товаров есть **SEO title** и **SEO description** — заголовок вкладки
браузера и описание в поисковиках. Можно не заполнять: тогда сайт возьмёт обычный заголовок. SEO description —
до 500 символов, разумно 140–160.

## Тексты страниц

**Кнопка:** Page texts / *Puslapių tekstai*. Новых страниц не создать — только правка существующих.

| Запись в списке (по первому заголовку LT) | Страница сайта | Медиа |
|---|---|---|
| «Nuo jūsų idėjos ar detalės…» | главная `/lt` | Video, Mobile video, Video poster, Logo, Favicon (PNG) — по одному файлу |
| «Inžinerija prasideda nuo supratimo.» | «О нас» `/lt/apie-mus` | Image — один файл |
| «Papasakokite, ką norite sukurti.» | контакты `/lt/kontaktai` | — |
| «Praktiniai 3D modeliavimo mokymai» | обучение `/lt/mokymai` (вводный блок) | — |
| «Privatumas ir failų saugojimas» | конфиденциальность `/lt/privatumas` | — |
| «Slapukų pasirinkimai» | cookies `/lt/slapukai` | — |
| «Pristatymas ir atsiėmimas» | доставка `/lt/pristatymas` | — |
| «Grąžinimas ir neatitikimai» | возврат `/lt/grazinimas` | — |

**Поля** у страниц называются техническими именами. Правило чтения: первая часть — блок страницы,
вторая — роль текста.

| Окончание | Что это |
|---|---|
| `_eyebrow` | маленькая надпись над заголовком блока |
| `_title` | заголовок блока |
| `_text`, `_note` | текст блока / примечание |
| `… 2 · Title`, `… 2 · Text` | вторая карточка или шаг блока: заголовок и текст |

Блоки главной: `hero_*` — первый экран (`hero_stages` — список этапов, по строке на этап), `services_*` — услуги,
`process_*` и `process_steps` — «как мы работаем» (4 шага), `scenarios` — 3 сценария, `equipment_*` —
оборудование, `partners_*` — партнёры, `news_*` — новости, `help_*` — блок помощи, `cta_*` — призыв в конце страницы.
«О нас»: `intro_*` (`intro_paragraphs` — абзацы, по строке на абзац), `panels` — 3 карточки.
Контакты: `details` — 5 блоков с подписью и текстом, `form_*` — подписи формы, `visit_note`.
Правовые: **Introduction**, `notice`, **Section N · Heading/Text**.

**Число карточек и шагов** в блоках страниц фиксировано: добавить пятый шаг или убрать карточку через бот нельзя.

**Видео главной**: Video — для компьютера, Mobile video — для телефона, Video poster — картинка до загрузки
видео; только MP4 до 20 МБ. **Favicon** — значок вкладки, только PNG (квадратный). Новый файл сразу заменяет прежний на сайте.

## Услуги

**Кнопка:** Services / *Paslaugos*. Страница: `/lt/paslaugos/<URL>`.

| № | Поле | Что это |
|---|---|---|
| 1 | Title | название услуги |
| 2 | URL | адрес страницы (не меняйте у опубликованных) |
| 3–4 | SEO title, SEO description | см. [SEO-поля](#seo-поля) |
| 5 | Short description | короткий текст под названием и в карточке услуги |
| 6 | Block caption | подпись блока преимуществ |
| 7 | Block points | **список** преимуществ, по строке на пункт |
| 8 | Description | основное описание |
| 9 | Problems | **список** задач, которые решает услуга, по строке |
| 10 | What should you provide? | что клиент присылает |
| 11 | What will you receive? | что клиент получает |

**Медиа:** + Image — **один файл**, новый заменяет прежний.
**Атрибутов нет.** Вопросы FAQ к услуге задаются в главе [FAQ](#вопросы-и-ответы-faq) (группа = услуга).
EN-версия новой услуги — см. [ограничение](#английская-версия-en).

## Проекты

**Кнопка:** Projects / *Projektai*. Страница: `/lt/projektai/<URL>`, список — `/lt/projektai`.

| № | Поле | Что это |
|---|---|---|
| 1–2 | Title, URL | название и адрес |
| 3–4 | SEO title, SEO description | [SEO-поля](#seo-поля) |
| 5 | Task | задача клиента |
| 6 | Solution | что сделали |
| 7 | Result | результат |

**Атрибуты** (сразу на сайте):

- **Related services** — несколько вариантов: отметьте услуги, которые использовались.
- **Application** — один вариант: Maintenance, Product development, Manufacturing (фильтр списка проектов).
- **YouTube URL (optional)** — ссылка `https://…` на видео проекта.

**Медиа:** + Image — **несколько файлов** (галерея), каждый новый добавляется.

Пример: Projects → Add a draft + → `Restauruota pavaros detalė` → `restauruota-pavaros-detale` → поля 5–7 →
Back → Related services: 3D scanning, 3D printing → Application: Maintenance → + Image (2–3 фото файлом) → LT →
Preview draft → Publish LT.

| № | Поле | Что это |
|---|---|---|
| 1–2 | Title, URL | заголовок и адрес |

**Разделы**: внизу списка всегда есть **пустой** следующий раздел — заполните его Heading и Text, и появится

**Атрибуты:** **Section** — News или Library (где показывать статью); **Category** — Materials,
File preparation, Technology. **Медиа нет.**

**Кнопка:** FAQ / *DUK*. Страница `/lt/duk` и блоки вопросов на страницах услуг.

| № | Поле | Что это |
|---|---|---|
| 1 | Title | вопрос |

**Атрибут FAQ group** (где показывать вопрос):

- название услуги — на странице этой услуги;

**Медиа нет.** EN-версию можно создать в боте: EN → поле 1 (Title), затем 2 (Answer), Publish EN.

## Что бот не умеет

Только в веб-админке:

- удалить запись, картинку или видео; поменять порядок записей и картинок;
- очистить поле, ссылку или дату;
- создать первую EN-версию услуги, проекта, статьи, товара или категории ([почему](#английская-версия-en));
- заказы, клиенты, платежи, счета, заявки с форм.

Бот не видит **исправленные** сообщения Telegram: если ошиблись — отправьте текст заново через кнопку поля.

## Сообщения бота и что делать

| Сообщение (EN / LT) | Что значит | Что делать |
|---|---|---|
| The code is invalid or has expired. / *Kodas neteisingas arba nebegalioja.* | неверный или старый код привязки | получите новый код в Integrations |
| *Ничего не отвечает* | не тот аккаунт или не тот чат; либо сайт недоступен | пишите с привязанного аккаунта в личный чат с ботом; иначе — к техническому администратору |
| Draft saved. / *Juodraštis išsaugotas.* | правка сохранена черновиком | при необходимости — Publish |
