## Для заказчика

- **Что готово.** Публичный сайт LT/EN по прототипу, калькулятор с заявкой, кабинет клиента и админка работают на этом
  компьютере. В админке есть контент, заказы, клиенты, настройки калькулятора, реквизиты счетов и интеграции.
- **Что ещё не работает по-настоящему.** Оплата Stripe, Google Таблица, Telegram-бот и отправка писем проверены только на
  имитациях. Для настоящей проверки нужны тестовые доступы (список — в
  [local-release.md §10](verification/local-release.md#10-что-требует-уровней-t-и-p-и-какие-нужны-доступы)).
- **Что нужно от вас до запуска:**
  - реквизиты продавца, ставка VAT и нумерация счетов (D-04, D-05, D-22, D-23, D-34);
  - тексты политик (D-27);
  - свои фото и видео. До их загрузки показываются медиа прототипа (D-43);
  - выбор сервера и почтового провайдера (D-01, D-15);
  - доступы Stripe, Google и Telegram.
- **Что посмотреть глазами** («ждёт проверки пользователем»):
  - кадры «наш рядом с прототипом» в `aiqme-site/build/verification/w21/part*-frames/report.html`;
  - нейтральные надписи и правки D-21 из `docs/progress.md`;
  - замечания Lighthouse о контрасте цветов прототипа (`local-release.md` §6).
- **Работа администратора.**
  - Вход — через обычную форму входа кабинета (`/lt/paskyra/login`). Администратор попадает в `/lt/administravimas`.
  - Контент правится в админке или через Telegram-бот (после привязки во вкладке Integrations). LT и EN публикуются
    отдельно.
  - Заказ: заявка → проверка файлов → подтверждение цены → запрос оплаты (аванс или остаток) → производство → трек →
    завершение. Счёт выпускается автоматически, когда заказ оплачен полностью и заполнены реквизиты.

## Для разработчика

- **Подготовка:** `aiqme-site/bin/setup`. Нужны Docker (PostgreSQL и Mailpit из `docker-compose.dev.yml`), Node 22
  через nvm и Python Playwright. Команды PHP запускаются через `aiqme-site/bin/php` (`bin/php artisan …`).
- **Проверки:**
  - `bin/check` — Pint, Node-тесты ядра, PHPUnit, Vite, границы Git и compose;
  - `bin/browser-check` — браузерная проверка, около 20 минут. Можно запускать частями: с путями и с `--signed-in`;
  - `bin/browser-check --base-url http://127.0.0.1:8792 --compose-file docker-compose.prod.yml` — локальный prod-compose.
- **Администратор:** `bin/php artisan aiqme:make-admin --password-stdin`. Служебных входов в обход формы нет.
- **Эксплуатация** (образ, prod-compose, расписание, копия, восстановление, требования к серверу) —
  [operations.md](operations.md).
- **Демо для GitHub Pages:** `bin/demo-build`, затем `bin/demo-check`. Каталог `demo/` отслеживается Git.
  Публикация — только по разрешению владельца (D-16).
- **Ход работ и решения по неопределённому** — [progress.md](progress.md). План —
  [docs/planning/edition-2/](../../docs/planning/edition-2/README.md). Следующие задачи: W-22 (тестовые подключения)
  и W-23 (рабочий запуск). Обе — только с доступами и разрешением владельца.
