# AIQME — локальный редизайн

Один адаптивный вариант сайта AIQME по мотивам светлого макета из `design_inside_excel.xlsx`. В текстах отражена возможность создать 3D-модель даже по фотографии; для точной геометрии могут потребоваться размеры и дополнительные ракурсы. Иллюстрации главного экрана и услуг вырезаны из макетов Excel; проекты и факты опираются на действующий сайт [aiqme.eu](https://aiqme.eu/). Старые варианты Copilot сохранены в `design-previews/` как архив; в сборку они не входят.

## Запуск

```bash
python3 -m pip install -r requirements-server.txt
python3 scripts/build_pages.py
python3 server/app.py init
python3 server/app.py serve
```

Откройте `http://127.0.0.1:8820/`. Страницы: главная с коротким STL-калькулятором и формой заявки, `/projektai/`, `/kontaktai/`, `/calculator/`, `/login/`. Для одного лишь просмотра публичных страниц можно запустить `python3 -m http.server 8820 --directory _site`; вход и отправка формы в таком режиме недоступны.

### Статическая демоверсия для GitHub Pages

```bash
python3 scripts/build_pages.py --mode demo
python3 -m http.server 8821 --directory _site_pages
python3 scripts/check_demo.py
python3 scripts/check_ui.py
```

Откройте `http://127.0.0.1:8821/`. В деморежиме оба STL-калькулятора работают в браузере, кабинет открывается кнопкой и показывает только вымышленные проекты. Форма показывает все шаги, но прямо сообщает, что заявка и файл не отправляются. Персональные данные не сохраняются. Сервер Flask и таблица заявок не входят в публикацию.

Опубликованный сайт: https://greatgleb.github.io/3d-fabrication-web/ . Git-репозиторий публикации находится в `github-pages/`, origin — `git@github.com:GreatGleb/3d-fabrication-web.git`, ветка `main`. Сборка `python3 scripts/build_github_pages_v2.py` сохраняет `.git`, использует оформление V2 и актуальный калькулятор из `site/`. Перед push: `STL_TEST_DIRECTORY=github-pages python3 scripts/check_stl_pricing.py` и `python3 scripts/check_github_pages_ui.py`. `_site_pages/` — отдельная демосборка; корневой workflow не используется для текущей публикации.

### Кабинет клиента

Клиентов и проекты сейчас создаёт команда через консоль, без админки и открытой регистрации. Пример:

```bash
python3 server/app.py create-client client@example.com
python3 server/app.py add-project client@example.com "Корпус датчика" --summary "Подготовка модели"
python3 server/app.py set-status 1 "В работе"
python3 server/app.py attach-file 1 /path/to/model.stl
python3 server/app.py set-password client@example.com
```

Пароль вводится интерактивно и не попадает в историю команд. Данные и файлы находятся в `instance/` вне каталога `_site/`; сохраните резервную копию этого каталога. Для другой директории данных установите `AIQME_DATA_DIR`. Кабинет показывает каждому клиенту только его проекты, статусы и прикреплённые файлы. Для публикации нужен HTTPS, `AIQME_HTTPS=1`, постоянная директория данных и WSGI-сервер вместо встроенного сервера Flask.

### Калькулятор

Короткий калькулятор на главной показывает габариты и объём. Полная страница дополнительно рассчитывает ориентировочную массу сплошной модели с учётом плотности и количества. Оба принимают бинарный или текстовый STL до 25 МБ. STL не хранит единицы измерения, поэтому их нужно выбрать. Для точного объёма нужна замкнутая сетка с правильно ориентированными гранями. Файл остаётся в браузере.

### Заявки

Форма на главной и странице контактов позволяет выбрать услугу, описать задачу, приложить один файл до 25 МБ и оставить контакты. Заявки и вложения пока сохраняются только в приватном каталоге `instance/`; уведомлений по почте и отправки в Google Sheets ещё нет. Просмотр заявок:

```bash
python3 server/app.py list-leads
python3 server/app.py show-lead 1
```

Команда `show-lead` показывает путь к вложению. Перед публикацией понадобится настроить постоянное хранение и доставку заявок команде AIQME.

Для браузерной проверки нужен Playwright (`requirements-dev.txt`) и Google Chrome или Playwright Chromium:

```bash
python3 scripts/check_pages.py
python3 scripts/check_portal.py
python3 scripts/check_demo.py
python3 scripts/check_ui.py
```

Первая проверка запускает сайт под вложенным URL и проверяет публичные страницы на ширинах 390, 768 и 1440 пикселей, включая расчёт тестового STL. Вторая проверяет вход, защиту проектов и файлов разных клиентов и интерфейс кабинета в браузере. Третья проверяет деморежим под вложенным адресом, оба калькулятора, форму и кабинет без запросов к API. Для проверок нужны пакеты из обоих файлов requirements.

## Структура

Папки первого уровня разделены на исходники, готовые сборки и вспомогательные материалы:

| Папка | Назначение |
|---|---|
| `site/` | Исходники основного сайта: HTML-шаблоны, стили, JavaScript, изображения, переводы, калькулятор и страницы. Здесь редактируют обычную версию сайта. |
| `design-previews/` | Галерея вариантов дизайна, ранние концепции и отдельные анимационные версии V1 и V2. Текущую V2 редактируют в `design-previews/animation-v2/`. |
| `_site/` | Готовая сборка основного сайта из `site/` для локального просмотра и работы с сервером. Создаётся командой `python3 scripts/build_pages.py`. |
| `_site_pages/` | Статическая демосборка основного сайта без сервера: кабинет демонстрационный, заявки не отправляются. Создаётся командой `python3 scripts/build_pages.py --mode demo`; это отдельная сборка от текущей публикации. |
| `_site_motion/` | Готовое сравнение обычной версии и анимационной V1. Создаётся командой `python3 scripts/build_motion_preview.py`. |
| `_site_motion_v2/` | Готовое сравнение обычной версии, V1 и V2. Создаётся командой `python3 scripts/build_motion_v2.py`. |
| `github-pages/` | Версия для публикации на GitHub Pages: оформление V2 и актуальный STL-калькулятор из `site/`. Содержит отдельный Git-репозиторий с историей публикаций. Собирается командой `python3 scripts/build_github_pages_v2.py`, которая сохраняет `.git`. |
| `scripts/` | Скрипты сборки, подготовки материалов и проверки калькулятора, интерфейса, анимаций, мобильного отображения и кабинета. |
| `server/` | Серверная часть на Flask: вход клиентов, проекты, файлы и обработка заявок. |
| `instance/` | Локальные данные сервера: база данных и загруженные файлы. Это данные приложения, которые нужно сохранять при резервном копировании. |
| `docs/` | Документация: исследования референсов, планы дизайна и анимаций, описания исправлений, результаты проверок и визуальные материалы. |
| `примеры/` | Сохранённые внешние референсы: локальная версия Relats и видеопримеры с Behance для изучения дизайна и движения. |
| `tools/` | Вспомогательные инструменты; сейчас здесь находится инструментарий сборки STL-загрузчика на базе Three.js для калькулятора. |
| `.github/` | Настройки автоматизации GitHub. Существующий workflow не используется для текущей публикации, которая ведётся через отдельный репозиторий в `github-pages/`. |

Правки основного сайта и калькулятора вносят в `site/`, а дизайна и анимаций V2 — в `design-previews/animation-v2/`. Папки `_site*` генерируются автоматически: ручные изменения в них пропадут при следующей сборке. Замороженные копии `baseline/` внутри анимационных вариантов не редактируют. Изменения для публикации сначала вносят в исходники, затем пересобирают `github-pages/`.

`design-previews/00-design-gallery/index.html` и `styles.css` относятся к галерее выбора вариантов дизайна, а не к основной странице сайта.

Полезные файлы и вложенные каталоги:

- `docs/design/relats-study/README.md` — подробное исследование анимаций Relats; [визуальная галерея](docs/design/relats-study/index.html), [приёмы для AIQME](docs/design/relats-study/motion-recipes.md).
- `примеры/relats/` — локальный архив референса с сервером для воспроизведения анимаций.
- `site/` — HTML-шаблоны и исходные ресурсы.
- `site/i18n/ru.json` — русский словарь всех текстов. Для нового языка добавьте полный словарь `lt.json`, `en.json` и соберите сайт заново; сборка создаст соответствующие языковые каталоги.
- `scripts/build_pages.py` — статическая сборка в `_site/`.
- `site/assets/ASSETS.md` — происхождение изображений и логотипа.
- `docs/design/design-audit.md` — визуальная сверка главной с последним светлым макетом Excel и перечень оставшихся отличий.
- `scripts/extract_excel_assets.py` — повторное извлечение иллюстраций из Excel.

## Статус и решения перед публикацией

Это локальный вариант для просмотра. Он не опубликован на aiqme.eu. Заявки из формы сохраняются локально; интеграция с Google Sheets отложена.

Для этой версии админка не нужна. До замены действующего сайта нужно подтвердить технические характеристики и перечень услуг, подготовить литовский перевод или согласовать запуск только на русском, а также выбрать способ обработки заявок. Публичные адреса `/projektai/` и `/kontaktai/` сохранены в локальной структуре.


## Обновление интерфейса

Кнопки и поля используют радиус 12 px, карточки — 20 px, крупные панели — 28 px. Обновлены калькуляторы, карточки, формы и мобильный первый экран. Загрузка файлов поддерживает локализованные подписи и удаление; калькуляторы игнорируют завершение устаревшего чтения файла. В заявке добавлены обозначение шага и ошибки возле полей.

Сравнение: `docs/design/modernization/index.html`. Дополнительная проверка `python3 scripts/check_ui.py` запускается после демосборки и проверяет адаптивность, сброс результатов, клавиатуру и обработку ошибок. Исходные фотографии проектов сохранены; в карточках они показаны целиком.

Исправления аудита и подтверждения: `docs/design/bugfixes/README.md`. Проверка новых регрессий: `python3 scripts/check_bugfixes.py` (после обеих сборок; нужны также серверные зависимости).

## Отдельная версия с анимациями

Сравнение обычной и новой версии: `python3 scripts/build_motion_preview.py`, затем `python3 -m http.server 8822 --bind 127.0.0.1 --directory _site_motion` → http://127.0.0.1:8822/. Основной сайт не заменяется. Исходники варианта, сохранённая копия и инструкция возврата: [design-previews/animation-v1/README.md](design-previews/animation-v1/README.md).
