# Архив проекта

> Прежний лендинг после реорганизации 18.10.2026 находится в `legacy-landing/`. Все команды и пути ниже выполняются и читаются **из каталога `legacy-landing/`** (`cd legacy-landing`); скрипты не зависят от текущего каталога, поэтому из корня можно вызывать их с префиксом, например `python3 legacy-landing/scripts/build_pages.py`.

- `design-concepts/` — ранние Precision / Studio / Process / Balanced и галерея; взаимное расположение ресурсов сохранено. Запуск: `bash archive/design-concepts/start.sh`.
- `github-automation/workflows/pages.yml` — прежний workflow основной демоверсии; не используется для публикации V2 и больше не находится в активном `.github/`. Пути сборки обновлены на случай явного будущего восстановления.
- `retired-checks/check_project_v2.py` — тест отменённой сцены `.project-feature`. Не включать в действующие проверки: сцена отсутствует по решению пользователя.
- `project-history/` — прежние README и AGENTS, сохранённые без редактирования. Сведения в них могут быть устаревшими; новые пути приведены в [карте переноса](../../docs/reorganization/README.md).

Отменённые исходники сцены оставлены на прежнем месте `design-previews/animation-v2/archive/scroll-scenes/`: это локальный архив варианта, сборщик его не подключает.

`reorganization-20261018/workspace-before.tar.zst` — полная копия всего рабочего пространства перед реорганизацией 18.10.2026 (включая `.git` публикации, `instance/`, `vendor/` экспериментов и предыдущий снимок); сверена с манифестом sha256, [отчёт](../../docs/reorganization/20261018/README.md). Содержит приватные данные — не публиковать.

`reorganization-20261015/workspace-before.tar.gz` — исходный локальный снимок до сборок и переноса (с `.git` и `instance/`, без `tools/stl/node_modules`). Сохраняет также прежние генерируемые файлы. Для восстановления сначала распаковывайте в отдельный пустой каталог.
