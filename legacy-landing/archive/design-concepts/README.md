# 3D klasė — dizaino kryptys

Keturi vizualiniai variantai būsimam 3D skenavimo, modeliavimo ir gamybos tinklalapiui.

## Paleidimas

Iš šios direktorijos arba iš projekto šaknies:

```bash
./archive/design-concepts/start.sh
```

Atidarykite http://127.0.0.1:8820/ ir pasirinkite variantą.

Kiekviename variante yra Paslaugos, Apie mus, Projektai, Informacija ir Kontaktai, taip pat demonstracinės užklausos, klientų zonos ir 3D kalkuliatoriaus formos. Formos yra prototipai: jos duomenų nesiunčia.
