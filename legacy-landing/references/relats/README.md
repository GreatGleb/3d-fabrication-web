# Relats — пример анимаций

> Прежний лендинг после реорганизации 18.10.2026 находится в `legacy-landing/`. Все команды и пути ниже выполняются и читаются **из каталога `legacy-landing/`** (`cd legacy-landing`); скрипты не зависят от текущего каталога, поэтому из корня можно вызывать их с префиксом, например `python3 legacy-landing/scripts/build_pages.py`.

Копия из `SP_MET_UAB/references/live`, источник: https://toptier.relats.com/.

Запуск из корня проекта:

```bash
bash references/relats/start.sh
```

Открыть http://127.0.0.1:8812/ в браузере. Остановка — Ctrl+C.
Порты 8810 и 8812 должны быть свободны.
При отсутствии зависимостей: `python3 -m pip install -r references/relats/requirements.txt`.

Скрипты и ресурсы сохранены в `cache/relats`. Обычный запуск работает без догрузки из интернета.
Это архив страницы для изучения анимаций; открывать нужно через сервер, не через file://.
По документации исходного архива три дополнительных изображения revitex/1.jpg–3.jpg отсутствовали и на оригинальном сайте.
