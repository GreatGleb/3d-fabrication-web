# Видео с Behance для AIQME

Подборка: `index.html`. Данные, источники и ограничения: `selection.json`.

Дата проверки: 30 сентября 2026. Базовая палитра сайта: #f7f9fc, #101820, #1168ff. Behance частично отвечает 403; доступные авторские страницы использованы для подтверждения медиа. Полный просмотр всех роликов не выполнен: для Bleu и Bosch проверены постеры, для Amazemet и Ori — кадры публичных видео авторских страниц, для Coinbase — описание авторов. Нельзя объявлять точное совпадение всех роликов с нашей палитрой.

Первый кандидат для светлого hero — Bleu. Для материала/металла — монохромный Amazemet в отдельной тёмной панели. Bosch тематически близок, но имеет зелёные акценты и конкретную технологию печати гранулами. Coinbase — предварительный кандидат по сценарию data → matter. Ori — только референс интерактивного сканирования, не видеоматериал для промышленной услуги.

Не установлена коммерческая лицензия ни на один выбранный ролик. Behance указывает, что права задаются отдельно для каждого проекта: https://help.behance.net/hc/en-us/articles/204485044-Guide-Copyright-And-Posting-Content-On-Behance . Возможность посмотреть видео/встроить авторский плеер не подтверждает право нарезать его и использовать как рекламу AIQME.

Перед внедрением нужны разрешение на коммерческое размещение, доступ к подходящему фрагменту без чужого брендинга, право на монтаж/перекрашивание/кадрирование и исходный файл. Не представлять чужой станок или работу как собственный кейс. Для главной нужны короткие немые MP4/WebM с постером, отдельным мобильным кадрированием и статичным reduced-motion вариантом. Пока не измерены пригодность для прокрутки, keyframes и мобильная загрузка.

Черновик обращения (не отправлен):

Hello! We are preparing a website for AIQME, a 3D scanning, CAD modelling and manufacturing service. We are interested in licensing a short excerpt from [project] for a commercial website hero/process section. Could you confirm availability, the rights holder, price and permitted usage? We would need permission to trim, loop, crop for mobile, adjust colours and remove audio, with MP4/WebM delivery. Please also confirm whether a neutral excerpt without client branding can be licensed and what attribution is required.

Подборка не изменяет `site/`, `build/server/`, `build/demo/` или `build/motion-v1/`. Временные полные файлы для оценки находились только в /tmp; в документации сохранены кадры с указанием авторов.
