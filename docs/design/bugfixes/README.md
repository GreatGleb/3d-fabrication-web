## Проверки

- `python3 scripts/check_pages.py` — публичные страницы, вложенный URL, изображения и расчёты.
- `python3 scripts/check_demo.py` — демоверсия, заявка и кабинет без API.
- `python3 scripts/check_portal.py` — вход, изоляция проектов/файлов, сохранение заявки и браузерные сценарии сервера.
- `python3 scripts/check_ui.py` — файлы, устаревшее чтение, клавиатура, адаптивность и ошибки.
- `python3 scripts/check_bugfixes.py` — новые регрессии и нормализация количества на сервере.

Для серверных проверок в этой среде использован `PYTHONPATH=/tmp/aiqme-server-deps`: зависимости Flask установлены отдельно от системного Python.

## Ограничения исходных изображений

Иллюстрации из Excel остаются небольшими растровыми вырезками. Их исходная детализация и уже обрезанные в источнике части не восстановлены. Исправления устраняют добавленную CSS-обрезку/прозрачность и видимые светлые подложки; новые изображения деталей не генерировались. Проверка выполнялась в Chrome, а не на всех браузерах и физических устройствах.

## Повторная проверка

Дополнительно обнаружен и исправлен случай незавершённого числа в поле плотности (`e`, `1e`): браузер может возвращать пустое `value` одновременно с `validity.badInput`. Теперь калькулятор отличает ошибочный ввод от действительно пустого необязательного поля. Одна функция проверки параметров используется при отправке и пересчёте. Регрессионная проверка покрывает ошибку до первого расчёта, после успешного расчёта и восстановление результата после исправления.

Повторно просмотрена граница раскладок 1100/1101 px. Ранее перечисленные ограничения исходных растровых изображений сохраняются.

## Проверка отправки при медленном ответе

Исправлено изменение данных между нажатием «Отправить» и получением CSRF-сессии: FormData фиксируется до ожидания, элементы формы блокируются, повторный submit игнорируется. После ошибки доступность элементов восстанавливается, данные сохраняются для исправления и повтора. Добавлена проверка `python3 scripts/check_pending.py`, использующая имитацию ответов без отправки настоящих заявок. Реальный серверный сценарий дополнительно проверяет `check_portal.py`.

При смене раскладки через 980 px меню теперь закрывается; фокус переводится с элемента, который становится скрытым, на доступную навигацию.
