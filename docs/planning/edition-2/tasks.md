# Задачи для workflow реализации

[← План](README.md). Источник истины — [tasks.json](tasks.json); этот файл сгенерирован из него (`python3 docs/planning/workflow/render_tasks.py`). Задачи последовательные, каждая рассчитана на одну рабочую сессию Codex. Workflow реализации **не запущен**.

## Общие правила

- Задачи выполняются по порядку; следующая начинается только после выполнения критериев завершения предыдущей или явной отметки о блокировке.
- Каждая задача — одна рабочая сессия Codex. После часа без заметного прогресса — остановиться, описать препятствие и предложить более простой способ.
- Приложение — только в aiqme-site/ (каталог aiqme-site/experiments/ — эталонный эксперимент, не изменять). Не изменять legacy-landing/ (включая instance/ и github-pages/), baseline, docs/customer/client, корневой AGENTS.md.
- Не публиковать, не делать push, не арендовать сервер, не вызывать внешние сервисы на уровне L. Уровни T и P — только с выданными доступами и явным разрешением.
- Отсутствующие реквизиты, доступы и секреты не заменять вымышленными рабочими значениями. Мок не закрывает уровень T.
- Решения D-xx применяются в варианте по умолчанию из decisions.md; отклонение — только по новому указанию пользователя.
- Каждая задача завершает работу записью в aiqme-site/docs/progress.md: что сделано, какие проверки запущены и их вывод, что не проверено.

## W-01

**Каркас приложения и инструменты** · L — локально · срез S1 · зависит от: —

**Результат.** Laravel-приложение aiqme-site/ с Lunar 1.5.0, Livewire 3.8.10, Stripe SDK 16.6.0 и версиями из composer.lock эксперимента; без отдельного Git внутри aiqme-site/ (весь корень — публичный репозиторий 3d-fabrication-web); docker-compose.dev.yml (PostgreSQL 17, Mailpit); Boost для Codex; bin/check; команда aiqme:make-admin.

**Входы:** `aiqme-site/experiments/lunar-aiqme/app/composer.json`; `aiqme-site/experiments/lunar-aiqme/app/composer.lock`; `aiqme-site/experiments/lunar-aiqme/bin/php`; `aiqme-site/experiments/lunar-aiqme/app/boost.json`; `docs/planning/edition-2/02-architecture.md`

**Затрагивает:** `aiqme-site/ (новый)`; `aiqme-site/.codex/config.toml`; `aiqme-site/docker-compose.dev.yml`; `aiqme-site/bin/check`

**Критерии завершения:**

- composer install воспроизводит версии эксперимента; отличия объяснены в progress.md
- Миграции Lunar и Laravel проходят на пустой БД
- Панель Lunar доступна только при AIQME_LUNAR_PANEL=true; в production-конфигурации маршрута /lunar нет
- aiqme:make-admin создаёт единственного администратора; регистрация через HTTP is_admin не выставляет
- Отдельный git init в aiqme-site/ не выполняется: весь корень публикуется в публичный репозиторий 3d-fabrication-web, git commit/push — только по указанию пользователя; .env, storage, vendor, node_modules исключены в .gitignore, секретов в коде нет
- Boost установлен с проектным .codex/config.toml; корневой AGENTS.md не изменён

**Проверки:**

- bin/check зелёный
- тест: маршрут /lunar отсутствует при выключенном флаге
- тест: POST регистрации с is_admin=1 не даёт прав

**Ограничения:**

- Не обновлять версии без проверки совместимости
- Не копировать .env, фикстуры и LocalTestAdapter эксперимента

**Неизвестные параметры:** [D-02](decisions.md#d-02), [D-14](decisions.md#d-14)

**Трассировка:** old_T: T-005, T-008, T-010; R: R-009; Q: Q-29-02
