## 1.5. Исключено и отложено целиком

- Маркетплейс пользовательских товаров — отложен.
- Генерация 2D/3D — исключена; анализ и просмотр загруженного STL допустимы.
- Форматы кроме STL, технологии и автоматическая производственная экспертиза.
- Многоролевой доступ, корпоративные кабинеты, второй согласующий, MFA.
- Массовые операции, сложные отчёты, CSV/Excel-экспорт, имитатор Telegram.
- Подключение перевозчиков, автоматические ярлыки, автоматическая передача в Bambu.
- TEJA — TODO после релиза (не отменяет автоматические счета сайта).
- Дополнительные рассылки, напоминания и автоматическое закрытие заказов.
- Перенос данных Flask и сохранение старых URL.
- Продажа демо-товаров и складской учёт.

## 1.6. Демо-сборка для GitHub Pages

R-041, задача [W-24](tasks.md#w-24). Кроме серверного сайта нужна статическая демо-сборка для GitHub Pages — показать оформление и сценарии без сервера.

| Часть | В демо | Ограничение |
|---|---|---|
| Публичные страницы LT/EN | Адреса со статусом 200 по [§4.6](04-content-seo.md#46-ожидаемые-статусы-адресов-прототипа) | Контент — заглушки и демо-данные, медиа прототипа по умолчанию ([D-43](decisions.md#d-43)); явная пометка «ДЕМО» на каждой странице; `noindex` |
| Калькулятор | Работает в браузере полностью: загрузка STL, параметры, оценка | Отправка заявки — демо-сообщение, без сервера |
| Формы обращений и обучения | Интерфейс и проверка полей в браузере | Не отправляются; сообщение «демо: данные не сохраняются» |
| Вход, регистрация, кабинет | Статические снимки экранов на демо-данных (§8.7) | Без авторизации, бэкенда и Livewire; переход в кабинет демонстрационный; разделов оплаты и счетов нет |
| Админка | Статические снимки экранов на демо-данных (§8.7) | Без Livewire; действия показывают демо-сообщение и не вызывают API |

Демо **не заменяет** серверный сайт: функции §1.2–1.4, §3–§6 реализуются и проверяются только в серверном приложении. Демо-режим не включается в рабочей конфигурации. Механизм — рекомендация [§8.7](08-operations.md#87-демо-сборка-для-github-pages-рекомендация); адрес публикации — [D-16](decisions.md#d-16) (по умолчанию https://greatgleb.github.io/3d-fabrication-web/aiqme-site/demo/). Публикация — только по отдельному разрешению.
