### Калькулятор и заявка на изготовление

| Шаг прототипа | Решение | Что делаем |
|---|---|---|
| 1. Загрузка: несколько файлов, drag-and-drop, ошибки формата/чтения, лимит | Р* | Только STL (ASCII/binary). Лимиты существующего ядра: 25 МиБ и 500 000 треугольников на файл; до 10 файлов в заявке (как в эксперименте). OBJ/STEP — сообщение «отправьте через контактную форму» (ветка специалиста), без конвертации |
| Модель: количество, единицы mm/cm/in, масштаб 1–1000 % с подтверждением новых размеров, вращение/масштаб/сброс вида, клавиатура | Р* | Ядро `site/assets/calculator.js`; масштаб меняет объём в кубе; просмотр — существующий three.js STLLoader. Нет WebGL или не хватает памяти — расчёт без просмотра (В-023) |
| 2. Параметры: технология, материал, цвет, качество, слой, заполнение, обработка, срок | Р* | Оценку формируют только параметры ядра: материал (плотность), заполнение, количество, единицы, масштаб. ## 1.5. Исключено и отложено целиком

- Маркетплейс пользовательских товаров — отложен.
- Генерация 2D/3D — исключена; анализ и просмотр загруженного STL допустимы.
- Форматы кроме STL, технологии и автоматическая производственная экспертиза.
- Многоролевой доступ, корпоративные кабинеты, второй согласующий, MFA.
- Массовые операции, сложные отчёты, CSV/Excel-экспорт, имитатор Telegram.
- Подключение перевозчиков, автоматические ярлыки, автоматическая передача в Bambu.
- TEJA — TODO после релиза (не отменяет автоматические счета сайта).
- Дополнительные рассылки, напоминания и автоматическое закрытие заказов.
- Перенос данных Flask и сохранение старых URL.
- Продажа демо-товаров и складской учёт.

## 1.6. Демо-сборка для GitHub Pages

Добавлено 18.10.2026 по указанию пользователя (R-041, задача [W-24](tasks.md#w-24)). Помимо серверного сайта нужна статическая демо-сборка для GitHub Pages, чтобы показывать оформление и сценарии без сервера.

| Часть | В демо | Ограничение |
|---|---|---|
| Публичные страницы LT/EN | Все маршруты §1.2, кроме исключённых §1.5 | Контент — заглушки и демо-данные; явная пометка «ДЕМО» на каждой странице; `noindex` |
| Калькулятор | Работает в браузере полностью: загрузка STL, параметры, оценка | Отправка заявки — демо-сообщение, без сервера |
| Формы обращений и обучения | Интерфейс и проверка полей в браузере | Не отправляются; сообщение «демо: данные не сохраняются» |
| Вход, регистрация, кабинет | Экраны на демо-данных | Без авторизации и бэкенда; переход в кабинет демонстрационный |
| Админка | Экраны на демо-данных | Действия не сохраняются и не вызывают API |

Демо **не заменяет** полноценный сайт на сервере: серверные функции (§1.2–1.4, §3–§6) реализуются и проверяются только в серверном приложении. Демо-режим не включается в рабочей конфигурации. Механизм — рекомендация [§8.7](08-operations.md#87-демо-сборка-для-github-pages-рекомендация); адрес публикации — [D-16](decisions.md#d-16) (по умолчанию https://greatgleb.github.io/3d-fabrication-web/aiqme-site/demo/). Публикация — только по отдельному разрешению.
