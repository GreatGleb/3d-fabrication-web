## 7.1. Что повторяем точно

- Шрифт `Arial, Helvetica, sans-serif` для всего сайта (вместо Ubuntu Sans в `site/assets/site.css`); body 15 px / 1,6 (≤600 px — 14 px).
- Hero: h1 `clamp(54px, 5.1vw, 82px)`, line-height 1,06, letter-spacing −0,047em, weight 500, max-width 950 px; абзац-ориентир «Skenuojame, projektuojame…» 21 px / 1,55, max-width 650 px, цвет `#c2cad4`; ≤700 px — h1 52 px, абзац 18 px. Общие заголовки — weight 500, line-height 1,12, letter-spacing −0,045em. Значения взяты из CSS и сверяются по поздним правилам каскада: последние media-блоки ≤700 px перекрывают ранние ≤600 px.
- Токены: `#0867ff`, `#11171e`, `#64717e`, `#dce2e8`, `#f3f6f9`, `#0a1119`; контейнер 1320 px, поля 48 / 28 (≤1150) / 20 px (≤600); шапка 82 / 75 (≤900) / 68 px (≤600), второй ряд ≥39 px; кнопки ≥48 px, радиус 3 px; фокус — outline 3 px, отступ 4 px.
- Брейкпоинты прототипа: 1150 / 1050 / 900 / 760 / 700 / 600 и min-width 1440; поведение сеток, каталога, калькулятора, кабинета и подвала — по [таблице аудита](../../customer-prototype/audit-20261016/visual-and-responsive.md#разные-классы-страниц).
- Светлый подвал (позднее правило CSS перекрывает раннее тёмное).

Разметка переписывается в Blade-компоненты. CSS прототипа переносится как основа (`resources/css/prototype/*.css`) с очисткой демо-классов, а не «на глаз».

## 7.3. Движение

- Hero-видео: muted, loop, playsinline, постер; разные MP4 для ≤700 px; автозапуск с учётом `document.hidden`, видимости (IntersectionObserver), reduced-motion и saveData; кнопка паузы; при ошибке — постер. Источник ролика — подпись со ссылкой, как в прототипе. Права на ролик Bosch / The Apic и другие референсы не установлены: до получения медиа заказчика допустимы заглушки (В-020).
- Ленты брендов (38 s, ≤700 px — 32 s) и новостей (48 s) с паузой; при reduced-motion — статичный вид без дублей. Пока разделы показывают заглушку, ленты не нужны.
- Hover: кнопки поднимаются на 1 px за 0,18 s, карточки услуг — на 4 px за 0,2 s.
- Эффекты V2 (мозаика, маски фото, длинные закреплённые сцены, плавающий CTA, вертикальные услуги, подвижная подложка навигации) **не переносятся**: в прототипе их нет.
- «СКАН → CAD → ДЕТАЛЬ» (`design-previews/animation-v2/assets/gear.js`, `scene.html`): исходники сохраняются. Сцена размещается, только если в композиции прототипа есть блок, совпадающий по смыслу и размеру; отдельная новая секция не создаётся. Проверка соответствия — часть W-05; если блока нет, сцена в MVP не показывается. Русские строки V2 в публичные версии не попадают. Отменённая крыльчатка не возвращается.

## 7.5. Устройства

Телефоны, планшеты, ноутбуки и настольные компьютеры (В-022). Проверка — эмуляция в отдельном Chromium (Playwright bundled), не в Chrome пользователя: 320×568, 390×844, 768×1024, 1024×768, 1440×1000 и 844×390. Это эмуляция, не реальные устройства; реальные устройства не проверялись. WCAG 2.2 AA — ориентир проектирования: семантика, клавиатура, контраст, масштаб 200 %, reflow 320 px. Формального заявления о соответствии нет. Озвучивание и системные флаги доступности не включаются.
