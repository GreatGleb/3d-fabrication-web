# Трассировка

[← План](README.md). Связь идентификаторов старого 30-слойного плана с редакцией 2; идентификаторы не перенумерованы, новое только R-041 (демо-сборка для GitHub Pages, 18.10). Таблицы Q и T составлены по `docs/planning/run/state.json` и [tasks.json](tasks.json) с проверкой полноты списка ID. Колонка «Где теперь» таблицы Q — справочная (где вопрос обсуждается или решается), с `trace.Q` задач не сверяется; где вопрос проверяется, задаёт `trace.Q` в tasks.json. Колонка «Задачи» таблицы R совпадает с `trace.R` задач в tasks.json (в порядке массива, включая итоговую W-21); расхождение ловит `python3 docs/planning/workflow/render_tasks.py --check`.
