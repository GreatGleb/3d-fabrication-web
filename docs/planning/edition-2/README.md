## Что строим

Сайт AIQME по [прототипу заказчика](https://aiqme-engineering-prototype.aiqme-9193.chatgpt.site/): тот же внешний вид, структура и согласованные сценарии, но реально работающие на сервере, с исправленными ошибками перевода и адаптации. Демо-данные и имитации прототипа рабочими функциями не считаются.

Стек: **Laravel 13.37 + Lunar 1.5.0, Blade/Livewire 3.8.10, JavaScript-модули для STL и анимаций**, PHP 8.4. Версии взяты из проверенного [эксперимента](../../research/lunar-vs-laravel-comparison-20261017.md) и его `composer.lock`; обновление версий само по себе задачей не является. Прикладные правила AIQME (заказ, цена, оплата, производство, контент) — отдельные сервисы, общие для веб-интерфейса, Telegram и обработчиков интеграций. Этот выбор заменяет Flask/Jinja2 и Laravel без торгового ядра.

Главный принцип: максимально просто и быстро. Делаем запрошенное заказчиком и предусмотренное прототипом с согласованными исключениями. Не добавляем функции только потому, что они есть в библиотеке или в старом плане. Проверки оплаты, прав доступа и сохранности заказов должны быть содержательными.

## Три уровня готовности

Каждая функция с внешней зависимостью проходит три независимых уровня. Отсутствие одного доступа не блокирует другую работу.

| Уровень | Что значит | Чем доказывается |
|---|---|---|
| **L — локально** | Код и тесты с подменой внешней границы (SDK-мок, локально подписанное событие, фейковый клиент Sheets, Mailpit) | `bin/check` зелёный; содержательные отрицательные тесты |
| **T — тестовое подключение** | Реальный вызов тестовой среды: Stripe test mode, тестовая таблица, тестовый бот, тестовый почтовый ящик | Запись в отчёте с датой и идентификатором тестового объекта; без доступа уровень остаётся «не проверено» |
| **P — рабочее подключение** | Реальные ключи, реквизиты, домен, рабочая таблица и бот | Только с явного разрешения; контрольный сценарий и откат |

Имитация не считается завершённой интеграцией. Отсутствующие реквизиты, доступы и секреты не заменяются вымышленными рабочими значениями.

После часа без заметного прогресса в задаче подход пересматривается — это правило пересмотра способа, а не отмена требования.

**Ночной прогон** (выбор пользователя 19.10, [D-39](decisions.md#d-39) «г», как ночь Flexiron): из этого checkout под своей учётной записью — `bash docs/planning/edition-2/run/night-run.sh` (пробно: `--only W-01`; чтобы пережил закрытие терминала — через `systemd-run --user`, см. начало скрипта). Скрипт требует чистое дерево, создаёт ветку `auto/night-<время>`, отключает push на время ночи; [run/night.py](run/night.py) коммитит каждую задачу, принятую `bin/check` и приёмщиком (отдельная сессия только для чтения; `AIQME_REVIEW=all|off|W-16,…`), и останавливает ночь на 15 % недельного лимита токенов; журнал и `СВОДКА.md` — в `~/.local/share/aiqme/night-<время>/`. Перед ночью выключить удалённую отладку Chrome (D-30). Прежний вариант с учётной записью `aiqme-run` ([run/prepare-aiqme-run.sh](run/prepare-aiqme-run.sh)) остаётся альтернативой.
