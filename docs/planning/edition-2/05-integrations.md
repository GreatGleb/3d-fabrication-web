# 5. Интеграции

[← План](README.md). Обязательные внешние подключения: **Stripe, почта, Google Таблицы, Telegram**, позже домен aiqme.com. TEJA, перевозчики и автоматизация Bambu не подключаются. Для каждой интеграции разделены уровни L / T / P ([README](README.md#три-уровня-готовности)).

## 5.1. События

| Событие | Почта | Google Таблицы | Прочее |
|---|---|---|---|
| Контактная форма принята | Письмо на info@aiqme.com | `Requests` + `Contacts` + `Events` | — |
| Регистрация на обучение | Письмо на info@aiqme.com | `Requests` + `Contacts` + `Events` | — |
| Заявка на изготовление отправлена | Письмо на info@aiqme.com (заявка — тоже форма) | `Orders` + `Contacts` + `Events` | — |
| Цена подтверждена / изменена | — | `Orders` (обновление) + `Events` | Журнал |

| Оплата прошла / не прошла / на сверку / возврат | — | `Payments` + `Orders` + `Events` | Журнал |
| Стадия производства, трек, отмена | — | `Orders` + `Events` | Журнал |
| Счёт выпущен | — | `Orders` (номер счёта) + `Events` | — |
| Восстановление пароля | Письмо пользователю | — (токены никуда не пишутся) | — |

Других писем нет: подтверждения клиенту, напоминания и рассылки не добавляются (В-052). Письмо и строка таблицы создаются только после сохранения основной записи. Их сбой основную запись не отменяет и успехом не показывается.

## 5.2. Почта

- Laravel Mail. Локально — Mailpit в Docker (бесплатно). Тестовый и рабочий транспорт — SMTP (D-15: почтовый ящик домена aiqme.com или транзакционный сервис, по выбору владельца домена).
- From — адрес домена из конфигурации; Reply-To — email клиента после валидации; в заголовки не попадает пользовательский ввод с переводами строк.
- В письме формы: тип, имя, контакты, услуга, краткое описание, число вложений и ссылка в админку. Сами вложения и полный текст — в админке, не в почте.
- Письмо сброса: ссылка из `APP_URL`, одноразовый токен со сроком; GET по ссылке не меняет пароль.
- Перед рабочим подключением проверить MX/SPF/DKIM/DMARC aiqme.com (D-15; DNS пока не исследовался).

## 5.3. Google Таблицы

- Односторонняя запись с сайта, на английском (В-053/054). Правки в таблице сайт не меняют. Вместо экспорта в админке есть ссылка на таблицу; доступ определяется правами самой таблицы, публичной она не становится.
- Подключение — сервисный аккаунт Google с доступом только к одной таблице; Sheets API v4 через `google/auth` и HTTP-клиент Laravel (**Рекомендация**: без тяжёлого `google/apiclient`). Ключ сервисного аккаунта — файл вне репозитория, путь в `.env`.
- Листы и колонки (английские заголовки, первая строка):
  - `Orders`: Order No, Created (UTC), Updated, Customer, Email, Phone, Company, Files, Production stage, Confirmed price EUR, Paid EUR, Due EUR, Payment state, Delivery, Tracking, Invoice No, Admin link.
  - `Requests`: Request ID, Type (contact/training), Created, Name, Email, Phone, Company, Service/Training, Summary (до 200 символов), Attachments, Admin link.
  - `Contacts`: Email (ключ), Name, Phone, Company, Company code, VAT code, Registered (yes/no), Last activity.
  - `Payments`: Request ID, Order No, Amount EUR, State, Created, Paid at, Stripe reference.
  - `Events`: Event ID (ключ), Occurred (UTC), Entity, Type, Summary, Amount EUR — это «история изменений».
- Upsert по ключу (номер заказа, ID заявки, email, ID события), а не по номеру строки: ручная сортировка или удаление строки не ломают обновление, пересборка восстановит строку. Значения записываются `RAW`, поэтому формулы во вводе остаются текстом. Деньги — строка `123.45`; «неизвестно» не записывается как 0.
- Один писатель: очередь `sheets` с одним worker-ом, `WithoutOverlapping` по сущности; перед записью задание перечитывает актуальное состояние из БД.
- Команда `aiqme:sheets-rebuild` пересобирает листы из БД без повторной отправки писем.
- Квоты Sheets API (300 запросов в минуту на проект) при малой нагрузке не ограничивают; 429 → повтор с задержкой.
- Часовой пояс таблицы — UTC в данных; отображение в таблице — на усмотрение владельца.

## 5.4. Telegram

Поведение — [§4.5](04-content-seo.md#45-telegram-бот-контент). Технически: тонкий клиент Bot API на HTTP-клиенте Laravel (sendMessage, editMessageText, answerCallbackQuery, getFile, setWebhook) без дополнительных пакетов. Webhook на рабочем домене HTTPS; локально — тесты на записанных фикстурах апдейтов. Тестовый бот (уровень T) создаётся через @BotFather на аккаунте владельца; long polling допустим только для ручной локальной проверки через команду `aiqme:telegram-poll`.

## 5.5. Stripe

Поведение — [§3.3](03-orders-payments.md#33-платёжные-запросы-и-stripe).

| Уровень | Что делаем | Нужен доступ |
|---|---|---|
| L | Мок `StripeClientInterface` на границе SDK; события, подписанные настоящим `Stripe\Webhook` с тестовым секретом-фикстурой; live-события отклоняются в нерабочих средах | Нет |
| T | Аккаунт Stripe test mode (бесплатно) на аккаунте владельца; тестовые ключи в `.env`; `stripe listen --forward-to` (Stripe CLI, бесплатно) для доставки webhook; тестовые карты успеха, отказа и 3DS; закрытая вкладка; повтор события из Dashboard; аванс + остаток; ручной возврат в Dashboard → `charge.refunded` | Тестовые ключи владельца |
| P | Live-ключи и отдельный webhook-секрет, endpoint на рабочем домене, контрольный платёж по согласованию владельца | Аккаунт продавца, реквизиты, разрешение |

Секреты test и live не смешиваются: разные переменные, проверка `livemode` у каждого события.

## 5.6. Не подключаем

TEJA (TODO после релиза), API перевозчиков и ярлыки, автоматический запуск Bambu Studio, Stripe Tax, Stripe Invoicing, внешние антивирусы и аналитика. Наличие блока в демо-админке не создаёт обязательства.
